# examples

单人口播样片的预期。仓库里故意不放成片和原片。

以后补一条样片时，放在 `examples/single-speaker/`，并满足下面的条件。

## 素材

- 一个人出镜，对着镜头说话
- 竖屏 9:16 为主
- 允许开场清嗓、看镜头发呆、重复 take、气口和口头禅
- 内容能归到方法论里的一种 `video_type`（例如日常单观点或直答成交）
- 不是多人轮流发言，也不是访谈剪辑

## 跑通之后应有的产物

| 产物 | 阶段 | 预期 |
|---|---|---|
| 带原句 id 的转写 | 1 | 原话可回溯，不改写 |
| 方向建议 | 1 | 1 到 4 个方向；此时没有成片 |
| 用户确认记录 | 1 与 2 之间 | 选定的方向 id，以及字幕、标题两个开关 |
| 粗剪工程 | 2 | 钩子落在成片前 3 秒；笑和自然气口还在；无关支线去掉 |
| 动效预设 id | 3 | 来自 `motion-pack/presets/`；未锁定时不能声称已配乐 |
| 封面与标题 | 4 | 关键词 + 数字 + 人；人物约占画面三分之二 |
| 成片 | 4 | 一条文件；人声不被 BGM 盖住；收段 CTA 听得清 |

样片说明里写清：原片从哪来、是否可再分发、转写是否含有需要匿名的客户信息。没有授权的素材不要提交。
