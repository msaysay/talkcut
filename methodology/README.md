## 剪辑管线如何使用本包

### Stage1「剪辑方向建议」

优先读取：

1. `03-edit-directives.md`（切点、钩子、节奏、强调）
2. `EDIT_PIPELINE_HOOKS.json`（结构化字段）
3. `02-content-conversion.md` 中「开—展—收 / 框架 / 开头类型」
4. `01-business-ip-system.md` 中「营销三问 / 视频类型」——用于判断成片任务（养需 / 选我 / 促现在）

Stage1 输出应回答：

- 本条属于哪种 `video_types`
- 开 / 展 / 收 各自从哪一段口播取
- 前 3 秒钩子选哪句
- 金句 / 数字 / 资格背书词何处打字幕或动效
- CTA 放在收段何处
- 封面 / 标题模式建议

### Stage2「粗剪」

严格按 `03-edit-directives.md` 与 `EDIT_PIPELINE_HOOKS.json` 的 `cut_heuristics` / `caption_emphasis` / `cta_patterns` 执行：

- 保留第一遍情绪最好的气口与自然反应（勿过度删「人味」）
- 开段压缩到「可停住」；展段按支撑块切；收段留清 CTA
- 字幕安全区、人物占比、名片条时机按指令执行
- 不做与业务无关的炫技转场

### 不加载到剪辑决策的内容

- 定价公式、团队配置、项目业绩叙事 → 仅作业务理解，不驱动切点
- 案例人名与品牌 → 已脱敏，若再出现应继续匿名化

## 语言与边界

- 全文 zh-Hans
- 不包含真实培训师 / 个人品牌名
- 案例统一为「高客单服务案例」「行业 A」「专家型 IP」等中性称谓
