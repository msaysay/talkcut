# 03 · 剪辑指令（机器可用 · 口播自动剪辑核心）

> 本文件只保留**驱动剪辑决策**的规则。Stage1 生成「剪辑方向建议」、Stage2 执行「粗剪 / 动效字幕」时必须遵守。

---

## A. 全局硬规则（AI 编辑器必遵）

1. **前 3 秒必须有钩子**：优先保留开场第一完整意群（提问 / 笃定判断 / 反差数字 / 纠正 / 喊话 / 强故事钩）。若口播前有清嗓、整理衣领、无效寒暄 → 建议切除或压到钩子之后作 B-roll。  
2. **一条视频只服务一个主任务**：为什么需要 / 为什么选我 / 为什么现在；或单观点支柱的「一件事」。勿在粗剪里拼多个互不相关主题。  
3. **开—展—收节奏清晰**：开 = 停住观看；展 = 建立信任；收 = 行动。三段边界应在方向建议中显式标出时间码或句界。  
4. **情绪优先于完美口播**：同一段落多条 takes，优先选情绪与对象感最好的一遍；轻微口误可留，勿剪到「朗读腔」。  
5. **保留人味**：笑、停顿、气口、自然反应默认保留；仅删明显失误、长时间沉默、重复口头禅堆叠。  
6. **人物为主体**：口播主体约占画面约 2/3；勿用过度花哨转场抢戏。  
7. **字幕不挡关键 UI**：字幕约在画面下 1/3，勿贴底；标题在平台安全区。  
8. **BGM 不压人声**：情绪框架可配乐，默认 ducking；自动音效宁缺毋滥。  
9. **收段 CTA 必须干净可听清**：引流口令、评论引导、咨询引导前后各留短静音或弱化 BGM。  
10. **合规保守**：夸大收益、无资质医疗/金融承诺、过度导流话术 → 方向建议中标注风险，粗剪不强化该类字幕。

## B. Stage1「剪辑方向建议」检查清单

生成方向建议时，逐项给出结论（可写「未检测到」）：

- [ ] `video_type`：日常单观点 / 数字清单 / 情绪向 / 消费心理成交 / 四力均衡 / 业务故事片 / 场景体验 / 产品说明 / 直答成交 / FAQ / 通知型  
- [ ] `journey_role`：为什么需要 | 为什么选我 | 为什么现在 | 破圈传播  
- [ ] `hook_candidate`：前 3 秒推荐句（原文 + 起止）  
- [ ] `opening_style`：提问 / 故事 / 笃定 / 对比 / 夸张 / 纠正 / 喊话  
- [ ] `structure_blocks`：开 / 展 / 收 的句段划分与建议时长占比  
- [ ] `support_blocks`：展段每个支撑点（数据/案例/经历…）切点建议  
- [ ] `gold_lines`：金句 1–3 条（建议大字幕或强调动效）  
- [ ] `numbers_to_punch`：需强调的数字  
- [ ] `credibility_phrase`：资格背书词位置（建议名片条弹出）  
- [ ] `cta`：收段行动指令原文与放置策略  
- [ ] `cover_title_pattern`：封面/标题模式建议  
- [ ] `keep_human_moments`：建议保留的笑/停顿/情绪峰  
- [ ] `cut_candidates`：建议删除的无效段列表

## C. 开—展—收 · 剪辑节奏指令

### C1 开（钩子区）

- **目标**：3 秒内给出「为什么值得看」。  
- **切**：删开场无效铺垫；若第一句弱、第二句强 → 以强句作冷开场，弱句可后移或删。  
- **强调**：钩子句可加轻微 zoom-in / 关键词字幕 / 短停顿。  
- **时长感**：短视频开段通常极短（数秒级）；业务故事片开段可至约 20 秒，但前 3–5 秒仍须有切口。

### C2 展（信任区）

- **按支撑块切**：一个支撑 = 一个叙事单元；块间可用短切或插入证据画面。  
- **数字出现时**：大字幕 + 可选计数/对比动效；口播说完数字后可短留白。  
- **案例/故事**：保留画面感细节；删重复解释。  
- **资格背书词**：首次完整说出身份/年限/结果时弹出名片条约 2–4 秒；短视频通常 ≤2 次。  
- **情绪峰**：勿在情绪最高点硬切；可在峰后自然落点切。

### C3 收（行动区）

- **顺序建议**：价值收束 / 金句 → 资格或产品点到为止 → CTA。  
- **CTA 类型**：评论区口令、私信关键词、预约、关注置顶、提问互动。  
- **切**：CTA 后的闲聊、重复感谢可删；CTA 本身不加速到听不清。  
- **互动型结尾**：「你愿不愿意…」「你怎么看…」可定格或延长 0.5–1s 便于完播互动。

### 建议时长占比（可按类型微调）

| 类型 | 开 | 展 | 收 |
|---|---|---|---|
| 日常单观点短视频 | 10–20% | 55–70% | 15–25% |
| 数字清单 | 10–15% | 70–80%（按点均分） | 10–15% |
| 消费心理成交 | 15–25%（痛点） | 45–55% | 25–35%（成交力+CTA） |
| 四力均衡 | 破圈 10% | 人设+专业 60% | 转化 30% |
| 业务故事片 | 前 20s 专项 | 主体成长路径 | 升华+号召 |

## D. 切点启发式（cut_heuristics）

机器粗剪时按优先级应用：

1. **删**：钩子前的无意义准备动作、长时间看镜头沉默、明显 NG 后的重说前半段（保留最佳 take）。  
2. **删**：同一观点的第三次以上同义反复（保留最清晰或情绪最好的一次）。  
3. **切**：话题跳到无关闲聊、幕后指令（「开始了吗」）、与成片任务无关的支线。  
4. **保**：反认知观点句、金句、带画面感的痛点描述、关键数字、客户原话式细节。  
5. **保**：笑、真诚停顿、情绪转折气口（除非明显技术失误）。  
6. **跳切节奏**：口播可微跳切去填充词（嗯、那个）但保持呼吸自然；勿切成机关枪。  
7. **对谈素材**：尽量切到「回答自洽」；提问可删，但回答须自带题目语境。  
8. **证据插入点**：在「我做过 / 数据是 / 客户反馈」类句子处插入 B-roll/截图；强情绪全屏口播优先。  
9. **业务故事片**：按「起点-冲突-萌发-求索-立志-行动-成果-升华」打章；章间可换 BGM 段落，勿一首铺到底。  
10. **直答成交片**：固定问句开场必须完整保留；疑虑问答可做成字幕问 + 口播答。

---

## E. 字幕与动效强调（caption_emphasis）

| 触发内容 | 处理 |
|---|---|
| 前 3 秒钩子关键词 | 大号字幕 / 高对比色，短时 |
| 反认知观点整句 | 逐句或关键词强调 |
| 数字、金额、年限、对比 | 数字放大、可短暂定格 |
| 金句 | 全句字幕 + 可选下划/轻震 |
| 资格背书词 | 名片条（中左、不挡脸）2–4s |
| 痛点画面感短语 | 关键词高亮 |
| CTA 口令（如评论区关键字） | 特大字幕 + 复述对齐口型 |
| 列表项（数字框架 1/2/3） | 序号徽章 + 每点切换 |

色彩：单条主色 ≤3；与人设/赛道一致。

---

## F. CTA 放置模式

- **默认**：收段最后 5–15% 时长内完整说出并留字幕。  
- **消费心理 / 四力转化**：可在展末预埋一次软钩，收段再给硬 CTA（勿开段硬卖）。  
- **通知型**：行动指令紧跟结果反馈句。  
- **长视频置顶类**：可在中段章节末加轻 CTA，片尾主 CTA。  
- **口令类**：字幕必须与口播关键字一致，避免错字导致转化失败。

---

## G. 封面与标题模式（单人口播）

### 封面

- 人物约占 2/3；表情匹配主题情绪（勿每条同一张标准照）。  
- 公式偏好：**关键词 + 数字 + 人（表情/立场）**。  
- 一眼回答：「这件事为什么值得我看完？」  
- 排版风格账号内统一，图与表情按条变化。

### 标题模式库（可组合）

1. 提问式：`你知道……吗？` / `为什么……还会……？`  
2. 数字式：`N 个……` / `……花了多少……`  
3. 反认知式：`真正……的人，往往……`  
4. 纠正式：`别再以为……`  
5. 喊话式：`……的人注意了`  
6. 盘点/最字：`最……的 N 个……`  
7. 对比式：`A 和 B，……差别有多大`  
8. 直答成交式：`为什么……会找我……`  

标题须与钩子句、封面词一致，避免题面党与内容脱节。

---

## H. 按视频类型的剪辑要点速查

### 日常 · 单观点支柱

只留一个观点；展段 2–3 个支撑；删支线；结尾带目的。

### 数字框架

每点结构对称；点与点之间硬切或短转场；超 3 点考虑拆条或先分类。

### 情绪框架

BGM 跟情绪曲线；少炫技；保呼吸与停顿；金句处留白。

### 消费心理

痛点段加画面感字幕；答案段清晰；成交力出现时名片条/案例插入；CTA 明确。

### 四力均衡

严格控制破圈开头占比；中段人设+专业；后段转化不抢戏也不省略。

### 业务故事片

前 20 秒四件套（切口、身份、成绩、观看理由）；证据链；BGM 分段；产品在「成果」段自然出现。

### 直答成交片

保留固定问句；答优势；可选案例；疑虑；咨询引导。骨架勿随意打乱。

## J. 明确不做

- 不为「热闹」加连续音效炸弹  
- 不把资格背书词打满全片  
- 不在开段堆产品参数  
- 不剪掉所有停顿导致假大空播音腔  
- 不把多条无关口播硬拼接冒充一条「开—展—收」
