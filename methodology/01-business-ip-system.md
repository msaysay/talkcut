# 01 · 商业 IP 系统（模块一精华）

> 工具内模块名：**商业 IP 系统**。目标：把账号建成「能成交的系统」，而不是押注小概率爆款。

## 1. 核心认知

- 做 IP ≠ 做自媒体；内容是线上生意的获客与成交载体。
- 目标组合：**变现确定性是底座，爆款是增益**（「变现不错，偶尔有爆款」）。
- AI 放大商业判断，不能替代定位与观点（人是「1」，工具是「0」）。

### 行业竞争三阶段（决策背景）

1. 红利期：供给少，粗糙内容也有机会  
2. 竞争加剧：差异化与经营能力决定结果  
3. 胜者为王：拼效率、认知、组织与复利  

多数赛道已过「随便发就有红利」阶段。

## 2. 起盘四问（无统一 SOP 可套）

1. **获客模型**是哪一类？  
2. **成交路径**把人带到哪里？  
3. 内容处在 **测试 / 复制 / 放大** 哪一阶段？  
4. IP 与协助者如何分工？

### 2.1 四类获客模型

| 模型 | 适用 | 内容重点 |
|---|---|---|
| 直接获客型 | 品类成熟、标准、案例易展示 | 结果、案例、为什么选我 |
| 漏斗获客型 | 平台限制或目标客户极稀 | 主张、观点、圈层议题，先扩再筛 |
| 促成获客型 | 重交付、长链条、已有销售 | 交付过程、实力、信任基础设施 |
| 影响力获客型 | 小圈层、认可持续 | 实力、话语权、圈层认可 |

可组合；先判当前阶段，勿永久贴标签。

### 2.2 四种成交路径

1. 短视频 → 橱窗 / 购物车 → 自助购买（低客单、标准品）  
2. 短视频 → 私信 → 产品（高客单、咨询型）  
3. 短视频 → 预约直播 → 产品 / 私信  
4. 直播 → 产品 / 私信（直播为成交主场）  

按产品成熟度、承接能力、客单价选择，勿从众。

### 2.3 内容运营三阶段

```text
内容测试 → 有效复制 → 投流放大
```

- **测试**：找 IP 擅长话题、观点、表达状态、可与业务结合的流量点  
- **复制**：同观点换案例 / 同结构换题 / 小变量迭代；反对「内容洁癖」  
- **放大**：同时具备流量、人设、业务关联、获客能力后再投流  

原则：**越做越收敛，沉淀 SOP，而不是永远追新创意。**

## 3. 高变现定位

```text
事的定位 = 问题 + 方案
人的定位 = 优势 + 风格
```

公式理解：

```text
高变现定位 ≈ 真需求 ×（说服力 + 心智占领 + 有效传播）
```

- **真需求**：看同行、行业推演、小规模私域测试——验证优先于空想  
- **说服力**：资格背书词（约 10 秒说清身份 + 年限 + 结果 + 壁垒）  
- **心智占领**：商业主张（能懂、能记、能感知结果，不过虚也不过碎）  
- **有效传播**：谁买 / 谁传产品 / 谁传观点  

### 人设两型

- **技术型**：专业硬实力驱动成交（多数商业 IP 够用）  
- **故事型**：经历与情感连接驱动（教育、情感、人生转变等）  

可交叉；关键是客户最终因为「硬实力」还是「故事连接」找你。

### 风格 = 成交信息的视觉化

问：目标客户希望服务者具备哪些品质？只放大「客户期待且你本有」的部分。

画面三原则：鲜明个人元素；与业务结合；只放自己舒适且真实的元素。

## 4. 营销三问（内容系统母题）

每条内容都应对准客户旅程中的一步：

1. **为什么需要？**（需求养成）  
2. **为什么选我？**（获客成交）  
3. **为什么现在？**（行动促成）  

成熟品类可少做「为什么需要」，把资源放在选我 / 现在。

建议用「成交循环」排期（例：一周 3–5 条），每条标明自己在链路中的任务，而不是随机发。

## 5. 账号店面（主页 = 线上门店）

```text
每条视频 = 传单 → 用户点进主页 = 店面
```

店面须迅速回答：你是谁、做什么、有何价值、下一步看什么。

### 5.1 头像 / 昵称 / 简介

- **头像**：高清、五官清晰、真实、与身份一致  
- **昵称**：`称呼 + 业务/行业 + 价值`（一眼可知你是谁、解决什么）  
- **简介四行**：身份 → 数字化成绩 → 账号价值 → 产品或发心  

### 5.2 置顶三条成交动线

| 置顶 | 工具名 | 任务 |
|---|---|---|
| 1 | **业务故事片** | 人设 + 产品 + 企业/方法，用故事讲清 |
| 2 | **场景体验片** 或 **产品说明片** | 有实体则云游览；无实体则系统讲产品 |
| 3 | **FAQ 疑虑片** | 集中处理付费前疑虑 |

三者共同解决：理解你 / 相信你 / 理解产品 / 消除顾虑。

## 6. 业务故事片（置顶重资产）

定义：把人设、产品、方法放进一条长口播，用讲故事完成「为什么需要 + 为什么选我（+ 为什么现在）」。

- **不是**个人苦旅炫耀  
- **是**用业务经历解释一个与客户/行业相关的问题  
- **明线**：在解决用户/行业/社会问题  
- **暗线**：观众自然得出「专业、投入、有解法、可信」

### 前约 20 秒（留存生死线）

1. 流量切口（够大、相关、可传播）  
2. 亮身份 / 资格背书词  
3. 摆可验证成绩  
4. 高级利他观看理由（谁该看、看完得到什么）  

### 正文成长路径

```text
起点 → 冲突 → 萌发 → 求索 → 立志 → 行动/方法 → 成果与产品自然出现 → 下一步/升华
```

产品勿硬插广告，应「因为解决了前面的问题，才形成这套方法」。

### 证据链

老照片、项目素材、客户场景、数据、现场画面；情绪高潮可全屏，证明经历可半屏穿插。

### 剪辑侧提示（细节见 03）

音乐随故事起伏；证据链穿插；前 20 秒钩子与资格词优先保护。

## 7. 场景体验片 / 产品说明片 / 直答成交片

### 场景体验片（云游览）

流量切口 → 10 秒资格背书 → 参访动线 → 专业与实力 → 场景表达理念 → 回应疑虑 → 结尾行动引导。

### 产品说明片

背景 → 资格 → 产品是什么 → 为何需要 → 如何解决 → 模块 → 优势 → 见证 → 下一步。不怕长：给高意向用户看懂。

### 直答成交片（结构骨架）

1. 固定句式开场：`为什么 + 目标客户描述 + 会找你 + 买你的产品/服务？`  
2. IP 答：最大优势、差异、成交理由  
3. 可选代表案例  
4. 处理常见疑虑  
5. 「怎么咨询」类提问引流  

初期先稳住骨架，再谈创新。

## 8. 单人执行提示（工具侧）

无协助者时：用**框架提示词**（选题、观点、支撑、人群、结尾），勿机械念满稿；先有框架再拍。

原则：**形式可变，内容任务为本。**
