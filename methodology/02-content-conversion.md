# 02 · 内容转化系统（模块二精华）

> 工具内模块名：**内容转化系统**。把内容当作成交旅程中的获客与成交载体。

## 1. 总链路

```text
业务定位
→ 用户成交旅程
→ 生意型选题
→ 用户地图（付费 / 流量桥梁 / 流量扩散）
→ 破圈技巧
→ 观点
→ 开—展—收
→ 具体内容框架
→ 表达与拍摄
→ 测试 → 复制 → SOP → 稳定获客
```

底层转变：**不要只当创作者；内容是生意系统中的获客与成交载体。**

## 2. 内容营销 = 认知迁移

```text
不感兴趣 → 刷到 → 注意 → 兴趣 → 理解问题
→ 认可观点 → 相信你 → 购买意愿 → 决策
```

每条内容问三件事：处在成交旅程哪一步？推动「需要 / 选我 / 现在」哪一个？对应流量、信任还是成交？

## 3. 三类选题

### 3.1 需求养成型（为什么需要）

认知升级、风险教育、成本/代价、种草、事件/现象。

### 3.2 获客成交型（为什么选我）

痛点拆解、人设信任、案例、通知型（新闻体）、方法路径拆解。

通知型排布示意：

```text
产品/活动名 → 现场正在发生 → 过去痛点 → 现在反馈 → 行动指令
```

### 3.3 破圈传播型（放大获客）

先扩大人群，再叠加流量技巧。

## 4. 用户地图（三圈）

| 工具名 | 定义 | 备注 |
|---|---|---|
| **付费人群** | 真正会付钱的人 | 写具体身份，勿只写人口统计 |
| **流量桥梁人群** | 自己未必买，但能把内容传给付费者 | 含上下游、专业伙伴、甚至同行 |
| **流量扩散人群** | 对更广人性议题感兴趣、愿互动传播 | 赚钱、情绪、健康、趋势、同城等 |

包含关系：内层成交直接，外层流量口更大。

桥梁愿意转发的条件：替他说难说的话、情绪出口、利益相关、风险提示、提升其专业形象等。  
**人转发是因为对转发者有价值，不是因为你想传播。**

## 5. 七类破圈技巧

1. 数字  
2. 揭秘  
3. 冲突（讨论 ≠ 极端对立）  
4. 反差  
5. 盘点  
6. 借势（借接口进业务话题）  
7. 「最」+ 强刺激词  

破圈选题 6 步：我是谁 → 地图里有谁 → 共同关注什么 → 我看到别人没看到的 → 态度 → 观点 + 流量技巧。

### 选题实操四工具

- **二创选题**：对标账号（基因匹配 / 变现能力 / 健康度）+ 关键词 + 验证选题  
- **翻拍结构**：拆标题封面结构镜头，换场景/案例/人群/业务  
- **热点**：可预测 / 突发 / 持续；判及时性、真实性、相关性  
- **选题魔方**：关系 × 冲突 × 标签 × 人性 × 流量词 × 角度  

## 6. 观点来源与筛选

九类来源：经验、不同视角、底层逻辑、高维视野、高赞评论、反认知、情绪宣泄、站队、痛点直击。

六标准：陌生、反认知、相关、深度、价值观一致、用户关心。

## 7. 视频母结构：开—展—收

```text
开：为什么值得看？（看点 + 传播）
展：为什么相信你？（专业 + 信任支撑）
收：为什么记住你 / 找你 / 行动？（人设 + 获客）
```

### 开

选题/话题 + 观点（优先反认知或高维视角）。

### 展 · 强支撑（选 1–3 个）

权威数据、专家说法、历史趋势、名人案例、实验/对比、算经济账、真实客户案例、亲身经历。

### 收

资格背书词、产品、价值总结/升华、钩子/互动/引流。

### 七种常用开头

1. 提问式（优先：聊天式小白问题，勿像采访）  
2. 讲故事  
3. 笃定式  
4. 对比式  
5. 夸张式  
6. 纠正式  
7. 喊话式  

## 8. 内容框架库

### 置顶向

1. 业务故事框架  
2. 场景体验 / 产品说明框架  
3. 直答成交框架  

### 日常向

4. **单观点支柱框架**（原「北极星」）：一条只讲清一件事 = 反认知观点 + 强支撑 + 人群垂直 + 带目的  
5. **数字框架**：1/2/3 结构化；7—3—1 记忆原则（3 最适合单条视频）  
6. **情绪框架**：先共鸣，再讲深；画面/BGM/节奏匹配情绪  
7. **消费心理框架**：痛点 → 答案 → 支撑 → 成交力 → 行动；痛点公式 = 具体问题 + 隐患后果 + 画面感  
8. **四力均衡框架**：破圈约 10% + 人设 30% + 专业 30% + 转化 30%  

同一选题可换框架拍 2–3 版做测试。

### 单观点支柱 · 拍摄提示卡字段

```text
选题 / 目标人群 / 核心观点 / 第一句话
强支撑1–2 / 关键数字 / 金句
资格背书词 / 结尾类型（互动|总结|升华|引流|口号）
BGM情绪 / 拍摄场景
```

勿写满逐字稿导致「朗读脸」。

## 9. 表达与说服（影响剪辑取舍）

- 观点笃定，少负向骑墙词（事实不确定时仍如实说）  
- 对象感：说「你」不说「你们」  
- **好情绪 > 好内容**：保留气口、笑、自然反应；勿因小口误把情绪拍废  
- 形象与承诺结果一致  
- 说服靠冷静/好奇/共鸣/自我思考，避免过度教育感与硬推销  

### 提问动线（对谈拍法）

操盘/协助者按「成片思维」设计问题链：场景 → 现象 → 冲突 → 观点 → 支撑 → 价值 → 结尾。  
IP 回答应把题目带进句子，拿掉提问后回答仍自洽。

## 10. 专家长视频（补充）

适合完整走完「需要 → 选我 → 现在」。选题：问题 / 现象 / 事件 / 流程 / 特殊时间。结构：原理、统计、全链路、对比、路径。封面公式：**关键词 + 数字 + 人**。

## 11. 收敛运营

每条有效内容沉淀：选题、观点、框架、开场第一句、场景、形式、长度、支撑、案例、风格、时间、结尾钩子、封面、标题、获客/转发/播放等。

```text
有效选题 × 观点 × 框架 × 开头 × 拍法 × 结尾 = 可重复内容系统
```
