# 4 · 成片

封面、标题和最终渲染。前三段的选择都已经落在工程里。

## 输入

- 已确认的方向、粗剪和动效预设
- `cover_title_patterns` 与封面公式：关键词 + 数字 + 人（表情 / 立场）
- 用户对「字幕」「画面标题」的独立选择。关掉画面标题不等于同意加封面标题

## 做什么

1. 标题与钩子、封面词一致，避免题面和内容脱节。
2. 封面里人物约占画面三分之二，表情跟这条片子的情绪走，不要每条都用同一张标准照。
3. 渲染一条成片。交付真实输出路径；预览和下载的是同一个文件。
4. 导出被引擎拒绝时，保留失败原因，不要换一句原话假装已经剪成。

## 输出

- 封面成图（用户需要封面时）
- 标题文本
- 最终成片路径与工程目录，便于继续改

## 尚未接入

封面排版与导出要等 `engine/` 移植 sayframe 的 `covers`、`planning`、`editor_export`。骨架里的 `cover` 与 `export` 会拒绝执行。
